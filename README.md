#  Codeforces Solutions (C++)

## Why I built this ?

### Situation
Consistent practice in competitive programming is crucial for mastering algorithms, but tracking progress and maintaining a reference library of solved problems can become disorganized.

### Task
I needed a structured repository to store, categorize, and document my solutions to complex algorithmic challenges on Codeforces.

### Action
I organized the repository by difficulty rating and topic (e.g., Dynamic Programming, Graph Theory, Segment Trees). For each complex problem, I included the source code along with optimal time and space complexity annotations, ensuring the solutions were not just functional, but highly optimized.

### Result
The repository serves as a personal knowledge base and demonstrates my proficiency in advanced data structures, algorithmic optimization, and the ability to solve edge-case heavy computational problems under constraints.
